# Referências

Referências são fontes de princípios, não modelos de identidade. O inventário de análises do [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) pode orientar pesquisa adicional; o conteúdo de cada marca deve ser conferido antes de ser considerado referência aprovada.
