# Interações

Use movimento para orientar uma mudança de estado e respeite `prefers-reduced-motion`; funcionalidades devem permanecer utilizáveis sem animação. Evite animações concorrentes. Filtros avançados podem ser revelados progressivamente, sem ocultar operações essenciais. Todo gesto deve ter controle alternativo por teclado e toque. Valide foco, mensagens de erro, carregamento e retorno de operações com leitores de tela quando pertinente.
